① 구글 시트 연동 설정

대시보드 하단 소스 코드 상단의 SHEET_ID 값을 본인의 구글 시트 ID로 교체하면, 시트 데이터를 새로고침할 때마다 자동으로 반영됩니다. 현재는 검증된 실제 공시자료 기준 데모 데이터로 표시되고 있습니다.

② Power BI에 연동하는 방법

  1. 이 HTML 파일을 사내 웹서버 또는 GitHub Pages 등에 업로드해 URL을 만듭니다.
  2. Power BI Desktop에서 시각화 패널 → "HTML Content" 사용자 지정 비주얼을 추가합니다.
  3. 측정값으로 위 URL을 만들어 비주얼의 "값" 필드에 연결하면 보고서 안에 이 대시보드가 그대로 표시됩니다.

③ 조직원에게 공유할 때 — 이 안내문 숨기는 법

지금처럼 안내 박스를 접어두면 조직원이 볼 때는 제목 줄만 보이고, 필요한 사람만 클릭해서 펼쳐볼 수 있습니다. 완전히 숨기고 싶으면 코드에서 .notice-bar 영역 전체를 삭제하거나 style="display:none"을 추가하면 됩니다.

④ 데이터 출처 및 주의사항

본 대시보드의 수치는 TB_공시자료.xlsx 원본을 기준으로 검증되었습니다. 일부 항목(2021년 학생·교원 지표, 2025년 취업률·연구실적·재정 지표 등)은 원본 공시자료 자체에 값이 없어 "—"로 표시됩니다. 경쟁대학 평균은 신성대학교를 제외한 14개교 기준이며, 일부 항목은 원본 시트의 누락으로 12~13개교 평균일 수 있습니다(해당 항목에 각주로 표시).
